# Muebles Los Alpes – ERP & E-Commerce System

ERP and e-commerce management system for a furniture company. Includes Oracle 21c database design, backend API development, and modular architecture for inventory, sales, purchasing, and user management.

## Project Structure

- `database/`: SQL scripts and database objects
- `backend/`: API and business logic
- `docs/`: diagrams, requirements, and technical documentation

## Team Modules

1. Auth & Usuarios
2. Catálogo & Inventario
3. Compras a Proveedor
4. Ventas & Facturación
