# Flujo de trabajo del equipo

## Rama base
- develop = integración del proyecto
- main = versión final/entrega

## Ramas por desarrollador
- feature/wilmer-auth-usuarios
- feature/ulices-catalogo-inventario
- feature/anderson-compras-proveedor
- feature/jose-ventas-facturacion

## Pasos para empezar
1. Clonar repositorio
2. Cambiar a su rama
3. Actualizar desde develop
4. Trabajar solo en su módulo
5. Hacer push a su rama
6. Crear Pull Request hacia develop
